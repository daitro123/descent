# Descent

A slower-paced, story-focused isometric pixel-art action game for the mobile browser. This glossary covers the proof-of-concept stage.

## Language

**Proof of Concept (PoC)**:
The first playable build, which exists to get the Feel right. It has one class, three Enemy types and one Area.
_Avoid_: demo, prototype (a prototype is a throwaway experiment that answers one question)

**Feel**:
How moving and fighting respond to the player's input on the phone: control response, movement, the weight of hits, the camera and readability.
_Avoid_: game feel, juice (as a synonym for the whole)

**Warrior**:
The only playable class in the PoC: a melee fighter.
_Avoid_: hero, player (the player is the person holding the phone)

**Enemy type**:
A kind of enemy with its own look and behaviour. The PoC has three.
_Avoid_: using "enemy" when you mean the kind

**Enemy**:
One instance of an Enemy type in the Area.

**Area**:
One contiguous, hand-built playable space. The PoC has exactly one.
_Avoid_: map (reserved for the wayfinder planning map), level

**Tuning panel**:
An in-game panel, opened with `?tune`, for adjusting Feel values live on the device.
_Avoid_: debug menu
